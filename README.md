# Projeto-SisGESC-
SisGESC é um projeto acadêmico de banco de dados para gestão educacional. Modela alunos, cursos, professores, turmas, matrículas e notas com foco em integridade, normalização (3FN) e SQL DDL. Inclui requisitos, DER, dicionário de dados e scripts, simulando um sistema real de controle acadêmico, administrativo e financeiro.
